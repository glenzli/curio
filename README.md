# Curio

Curio 收录我感兴趣、愿意长期研究，并与 AI 一起认真写成的书。选题、取舍、判断和
最终修订由我负责；AI 参与资料查阅、推导、写作和校验。

每本书独立维护正文、图版、参考资料与修订记录。重要结论给出推导或来源，技术图
尽量由可复现的模型生成。内容会随着理解加深和发现的问题持续修订。

维护者：[glenzli](https://github.com/glenzli)。

## 书架

- [摄影成像科学：从光子、CMOS 到镜头与 RAW](books/photographic-imaging-science/)：
  从曝光和光电转换讲到 CMOS 读出、噪声、色彩、RAW 与镜头成像。含序章和 17 章
  正文、49 幅技术图、70 道练习及逐题答案。

## 阅读与修订

从各书的 README 进入目录。参考资料、符号和审校记录随书维护；教材写作约束见
[books/SKILL.md](books/SKILL.md)。

使用 Python 3、Node.js 22 或更新版本和 Git，运行全部现有检查：

```bash
make check
```
