# 符号与约定

本轮图像与重复实验的局部记号：第12章 $I_{ij}$、$J_{ij}$ 是归一化线性强度细格，
$K_{ab}$ 是权重和为一的有限PSF核；$c$ 为重新归一之前相对离散全场的截取比例，
$\Delta=1.1\ \mu\mathrm m$ 为细格间距，$b\Delta$ 为像素节距。第17章 $L,A,R$
分别是样品数、每支装夹数和每次张数，均至少为二；$\mu$ 此处为MTF总体均值，
$\sigma_\alpha^2,\sigma_\beta^2,\sigma_\varepsilon^2$ 为三层生成方差，$M_\alpha,M_\beta,M_\varepsilon$
为式 (17.4) 的观测均方。这些局部符号不改写其他章节的辐亮度、半径或电荷记号。

## 辐射与曝光

| 符号 | 含义 | 单位 |
|---|---|---|
| $\lambda$ | 真空波长 | m，常用 nm |
| $h$ | Planck 常数 | J s |
| $c$ | 真空光速 | m/s |
| $L_{e,\lambda}$ | 光谱辐亮度 | W m$^{-2}$ sr$^{-1}$ m$^{-1}$ |
| $L_v$ | 光度学亮度，测光模型使用 | cd/m$^2$ |
| $K_m$ | 反射式测光校正常数，单位随亮度与曝光指数约定 | 依式 (5.1) |
| $E_{e,\lambda}$ | 光谱辐照度 | W m$^{-2}$ m$^{-1}$ |
| $H_{e,\lambda}$ | 光谱曝光量，$\int E_{e,\lambda}dt$ | J m$^{-2}$ m$^{-1}$ |
| $t$ | 曝光时间 | s |
| $f$ | 有效焦距 | m 或 mm |
| $D$ | 入瞳直径 | 与 $f$ 同单位 |
| $N=f/D$ | 工作条件另行说明时的相对孔径数（f-number） | 无量纲 |
| $T$ | 镜头透射率；避免与曝光时间 $t$ 混用 | 无量纲 |

Poisson 分布写作 $N\sim\operatorname{Poisson}(\mu)$，于是
$\mathbb E[N]=\operatorname{Var}(N)=\mu$。独立随机变量的方差相加。

## 光学与成像

| 符号 | 含义 |
|---|---|
| $n(\lambda)$ | 材料折射率 |
| $V_d$ | 以 Fraunhofer $d,F,C$ 线定义的 Abbe 数 |
| $\boldsymbol r=(x,y)$ | 像面坐标 |
| $\boldsymbol\nu=(\nu_x,\nu_y)$ | 空间频率，单位 cycles/mm 或 cycles/pixel |
| $h(\boldsymbol r)$ | 非相干强度点扩散函数（PSF），归一化积分为 $1$ |
| $H(\boldsymbol\nu)$ | OTF，即 $h$ 的 Fourier 变换 |
| $\operatorname{MTF}(\boldsymbol\nu)=|H(\boldsymbol\nu)|$ | 调制传递函数 |
| $p$ | 像素节距 |
| $\boldsymbol\xi,a_p$ | 物理瞳坐标与瞳半径；$\boldsymbol\rho=\boldsymbol\xi/a_p$ 为归一化坐标 |
| $\nu_N=1/(2p)$ | 一维 Nyquist 空间频率 |
| $\ell_1,\ell_2$ | 厚系统参考面与两主平面之间的有向距离 |
| $W,\sigma_W$ | 波像差及去除声明模式后的瞳面 RMS |
| $\mathcal S$ | 固定像面内的 Strehl 峰值比，相对于相同瞳振幅与总通量的无像差参考峰值 |
| $S_0$（第13章） | 固定参考原点的轴上强度比；峰值在原点时才等于 $\mathcal S$ |
| $\ell(x)$ | 沿一方向积分二维 PSF 所得的 LSF |
| $H,s_N,s_F,c_0$ | 第十六章超焦距、近景深界、远景深界与容许弥散圈直径 |
| $\alpha_T$ | 材料线膨胀系数，单位 K$^{-1}$ |

Fourier 变换统一采用
$$
\widehat f(\boldsymbol\nu)
=\int_{\mathbb R^2}f(\boldsymbol r)
e^{-2\pi i\boldsymbol\nu\cdot\boldsymbol r}\,d^2\boldsymbol r.
$$

第1章有限圆瞳小节局部采用$a,z,h$表示瞳半径、两平面轴向距离与像点高度，
三者用同一长度单位；$\theta=\arctan(h/z)$指向出瞳中心。该处$h$不是Planck常数。
第11章截光例中，$\boldsymbol h=(h_x,h_y)$为入口坐标（mm），$u$为近轴倾角（rad）；
$A_i,B_i$把入口高度和倾角映到第$i$个孔面，$c_i,r_i$为映回入口平面的圆心与半径（mm）。

第15章斜入射小节中，$\kappa=n_j\sin\theta_j$无量纲，$d_j,\lambda$同用nm；
$Y^{(s)}=n\cos\theta$、$Y^{(p)}=n/\cos\theta$为归一化切向场导纳，
$\delta_j=2\pi n_jd_j\cos\theta_j/\lambda$用rad。$r,t$采用切向电场振幅，
$T_\sigma=(Y_s^{(\sigma)}/Y_0^{(\sigma)})|t_\sigma|^2$；$Y_s$的下标表示基底。
$w_p$是入射能流中p偏振的比例，s/p反射与透射按功率加权。时间约定为$e^{+i\omega t}$。

## 码值与色彩

- “线性”默认指码值与到达相应通道的曝光量成正比，不表示已经是场景绝对辐亮度。
- $x$ 常表示归一化线性相机信号，$v=f(x)$ 表示 OETF 或 Log 编码后的码值。
- RAW 马赛克样本以 $R,G_1,G_2,B$ 表示；去马赛克后的相机 RGB 向量写作
  $\boldsymbol c_\mathrm{cam}$。
- $W_b$ 表示白平衡对角矩阵，$\Sigma$ 表示声明坐标中的噪声协方差矩阵。
- 第7章四波段教学例中，$S_0$ 为参照相机的 $3\times4$ 响应矩阵，
  $\boldsymbol q=(1,-1,1,-1)^{\mathsf T}$ 为其零方向；
  $\boldsymbol\varrho$ 为分段反射率，$\boldsymbol e$ 为相对谱曝光密度。
  积分除以75 nm后得到无单位的相对线性响应，不能当作显示RGB或人眼XYZ。
- 第8章二维配准中，$x,y$ 向右、向下为正，$d_x,d_y$ 是生成位移，
  $s_x,s_y$ 是观测搜索的对应偏移，均用px；匹配 $R(x,y)$ 与 $M(x+s_x,y+s_y)$。
  $\Omega$ 在所有候选间固定，$\rho(\boldsymbol s)$ 为归一化相关系数，非置信度。
- 曝光值差一档表示曝光量乘以 $2$；$n$ 档对应比例 $2^n$。
- 强度比的分贝采用 $10\log_{10}$；幅度比采用 $20\log_{10}$。本书的传感器
  动态范围以电子计数比定义，行业惯例写为 $20\log_{10}$，并同时给出 stop 值
  $\log_2$ 以避免歧义。

第四章校准漂移中的 $\delta$ 为电子刻度的固定偏置；式 (4.6a) 的 $b$ 为背景噪声
方差，两者不共用同一符号。贯穿算例中的参数只由序章固定表及明确的条件变更给出。

## 本批演示的局部符号

第三章斜坡误差用$\tau=t/T_\mathrm{scan}$、无量纲曲率$a$和列电压偏置$b_j$（V）；
$v_k$为时钟阈值（V），$\Delta=V_\mathrm{FS}/L$为理想LSB。该处INL按固定端点阈值定义。
第七章$Z_j,Z_c$为独立标准正态变量，$\sigma_c$为共同读噪（e$^-$ RMS），
$W$为白平衡、$M_\beta$为教学混合矩阵。变换后用e_ref表示输入电子参考刻度，非新电子。
第五、九章EI例用$g=2^{s_E}$表示EI倍率、$v$表示额外实际曝光档位，$r$为编码前增益；
$Q_\mathrm{file}$为连续标称文件上限（e$^-$），$c_R,c_L$为RAW/Log码（DN），
$d$为无量纲教学监看码。$H$在该例中为中灰上方档数，与波动光学OTF按章节区分。


## 全书展示扩展中的局部参数

- 第2章 $z_0,L_c$ 分别为入口失效层厚度与收集衰减长度（μm），$1/\alpha$ 为吸收穿透长度。
- 第4章 $M,N$ 为校准与科学帧张数，$b$ 为校准后的均值偏差（e$^-$），$v_c,v_s$ 为单帧方差；$s$ 为指定SNR下端。
- 第6、17章 $x,y$ 为归一化像场坐标，$C,A,K$ 为角点平均焦面、方向分离半值与传感器弯曲量（μm），$z_0$ 在此表示整体对焦位置。
- 第7章插值例 $X_j$ 是独立原始同色样本噪声，$Y_i$ 是插值输出，码值单位DN；与白平衡例的电子参考刻度分开。
- 第8章局部运动例 $t_i$ 以短曝光时长为单位，$L$ 为每短曝光的期望电子数；估计权重用观测初估 $L$，真值支路保留已知 $L$。
- 第9章 $T_k$ 为教学色调肩部，$k$ 为无量纲起点；捕获上限 $Q$ 与显示增益 $g$ 单独规定。
- 第12、13章 $z,z_j,\Delta_j$ 为同一像面坐标中的位置与离焦（μm），$\beta_j=\pi\Delta_j/(4N^2\lambda_j)$ 为圆瞳二次相位系数，$\lambda_j$ 此式也用μm；检测权重按强度归一化。
- 第13章畸变例 $k$ 与 $r$ 均无量纲，局部面积尺度为 $(1+kr^2)(1+3kr^2)$。
- 第14章 $a_b$ 为镜筒线膨胀系数（K$^{-1}$），$b=dn/dT$ 在该热模型中用K$^{-1}$；它不是第4章的电子偏差。
- 第15章 $A_4$ 用mm$^{-3}$，$z,r,R$ 用mm，$dz/dr$ 无量纲；图中矢高差单独换成μm。
- 第8.5节 $u,\delta_i,a,\sigma_o$ 均用px，$f$ 用cycle/px；$\boldsymbol c\in\mathbb R^{33}$
  是实Fourier系数，$A$ 为前向观测矩阵，$\lambda\ge0$ 是该处最小二乘正则系数，
  与光学波长分开。强度和观测噪声以相对线性刻度表示。
- 第13.7节 $u,v,\rho$ 是除以等面积瞳半径 $r_0$ 后的无量纲瞳坐标；$c,s$ 为以波长
  为单位的波前多项式系数，仅完整圆盘时可称RMS系数。$\Delta z$ 用μm、沿像方轴正向，
  表示实际像面相对名义焦面的移动；在此传播约定下正 $c$ 对应负 $\Delta z$。
- 第15.6节 $(z,y)$、带符号曲率半径 $R$ 均用mm，$u=dy/dz$ 是反向传播时仍保持的
  全局近轴斜率；$R_s,R_p$ 为无量纲功率反射率。41条子午光线各有同样的输入权重，
  功率百分比相对该离散输入，不代表二维孔径面积积分。
- 第3章二维列条带中 $Y_{y,j},Y^0_{y,j},D_{y,j}$ 分别是带偏置、无偏置与校准观测
  （DN），$\widehat d_j$ 为相对稳定参考列的校准码差，$r_{y,j}$ 为误差残差（DN）；
  $V_\mathrm{cal}$ 用V。参考列下标从0起，RMS不先减残差均值。
- 第4章重复PTC用 $K=24$ 表示整套采集次数，$\widehat g_k$ 为第 $k$ 次增益估计，
  $\overline g,s_g$ 是参数均值与N−1样本标准差，单位均为DN/e$^-$，与帧内方差分开。
- 第7章多频纹理中 $a_\ell$ 为无量纲强度幅度，$f_{x,\ell},f_{y,\ell}$ 用cycle/px，
  $\phi_\ell$ 用周期数；$w,\sigma_o,d$ 为像素积分宽度、光学Gaussian标准差和横移（px），
  $H_\ell$ 为相应振幅乘数。等价RGB在滤波后的有效图像上定义。
