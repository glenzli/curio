# 数学与物理教材的 OET 本体严格性标准

本文件沿用 OET 写作中对对象、命题和证明责任的要求，作为本仓库数学、数学物理与理论物理教材的共享严格性基线。这里的“形式”指对象、命题和证明责任的形式完整，不要求 Lean 代码，也不要求把所引用的外部学科重新证明一遍。

## 1. 对象层

每个新对象必须先说明下列数据中适用的部分：

1. 所在集合、空间、范畴或模型；
2. 底域、系数环、素数、宇宙或小性层级；
3. 定义域、值域以及映射的方差；
4. 拓扑、完备化、滤过、分次、作用或等变结构；
5. 物理理论中的自由度、背景、单位制、号差和规范约定。

同一个符号改变类型时必须重新声明。坐标公式、选基公式和规范固定后的公式，不得不加说明地升级为内禀陈述。

## 2. 良定义与退化情形

定义后必须立即检查会影响后文的良定义性：

- 商、极限、余极限、张量积、导出函子或局部化是否存在；
- 无界算子的定义域、闭性和共同不变核是否足够；
- 空对象、零对象、零半径、零模、奇异点、无穷值和不收敛情形如何处理；
- 上确界、下确界、比值、对数、逆元和行列式在边界上是否有定义；
- 物理近似在何种尺度、耦合、能区或渐近极限中成立。

若表达式在某个边界情形未定义，应明确排除该情形，不能用非正式约定掩盖不定式。

## 3. 定理陈述

定理、命题、引理和推论必须给出足以独立判断真假的陈述：

1. 量词和变量范围完整；
2. 所有假设在结论之前列出；
3. 结论的类型明确；
4. 局部、整体、逐点、几乎处处、同伦意义和导出意义不得混用；
5. 等式、自然同构、拟同构、同伦等价、范畴等价、Morita 等价和物理对偶必须分层书写；
6. 必要条件、充分条件和充要条件不得互相替代；
7. 定理不得比证明实际覆盖的范围更强。

## 4. 证明责任

正文中的非平凡陈述只允许以下四种终态：

- **书内定理**：给出覆盖全部结论的证明；
- **外部输入定理**：给出精确陈述、用途、来源和不在书内证明的边界；
- **推导或计算**：列出起点、逐步变形、使用的恒等式及适用条件；
- **猜想、启发式或研究边界**：明确说明其非定理身份。

“证明草图”不是书内定理的最终证明状态。若省略的是本学科主线中的有限论证，应补全；若依赖大型外部理论，应改标为“外部输入定理”，草图只能作为证明路线，不能承担证明完成的声明。

证明应满足：

1. 每一项结论均被覆盖；
2. 使用前文结果时指出具体结果或完整重述所需部分；
3. 存在性、唯一性、自然性、函子性、收敛性和独立于选择分别证明；
4. 复合、拉回、推出、交换极限、交换积分或逐项求导时写明合法性条件；
5. 反证法、归纳法和极限论证明确给出归纳对象、矛盾点或收敛模式；
6. “同理”只用于完全相同且变量替换已说明的论证。

## 5. 外部输入

外部输入必须记录：

- 可引用的定理名称或准确主题；
- 本书使用的精确版本和全部必要假设；
- 在正文证明链中的用途；
- 一手资料或公认专著中的定位；
- 本书没有重证的原因。

不能把“经典”“标准”“众所周知”当作来源，也不能给外部深定理附一段启发式文字后写“证毕”。若精确定理编号尚未核对，应诚实标为书目定位待校，但该状态不计入出版级闭合。

## 6. 数学物理与理论物理的附加要求

物理公式还必须区分：

- 运动学恒等式、经典场方程、量子算符恒等式和路径积分启发式；
- 精确陈述、微扰展开、半经典展开、有效理论截断和数值近似；
- off-shell、on-shell、规范固定后和规范不变的陈述；
- 可观测量、辅助场、坐标分量和规范依赖中间量；
- 已证明数学定理、标准物理输入、实验事实和物理猜想。

渐近式必须说明展开参数与余项口径；有效理论必须说明自由度、对称性、截断阶和适用能区；量子理论中的无界算子、路径积分和重整化步骤必须分别声明数学定义或物理输入边界。

## 7. 章节闭合判据

一章只有同时满足下列条件，才可标为“本体闭合”：

1. 新对象均已定义并做类型检查；
2. 本章主定理均处于上述四种终态之一；
3. 证明没有遗留未声明的存在性、收敛性或选择独立性义务；
4. 外部输入能从来源索引回到正文用途；
5. 例子至少验证关键定义，反例指出失败的具体假设；
6. 练习不承担正文主线中不可缺少而又未证明的结论；
7. 符号、单位、交叉引用和 LaTeX/Markdown 在目标阅读器中可解析。

## 8. 本标准不要求的事项

本标准不要求：

- 把基础集合论、泛函分析、代数几何或偏微分方程全部重建；
- 为每个定理提供 Lean、Coq 或 Agda 证明；
- 把物理路径积分伪装成已经完成测度论构造的对象；
- 为了“自足”而写短小但不真实的伪证明。

正确做法是：书内主线完整证明，边界外的深结果精确引用，尚无严格数学构造的物理步骤诚实标注。
